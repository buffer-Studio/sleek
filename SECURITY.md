# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Sleek, please do **not** open a public GitHub issue.

Instead, report it privately using GitHub's **Private Vulnerability Reporting** feature under the **Security** tab of this repository, or contact the maintainers directly.

Include as much detail as possible:

* Description of the vulnerability and its potential impact.
* Steps to reproduce or a minimal proof of concept.
* Any suggested fix or mitigation.

We will acknowledge your report and work on a fix as quickly as possible.
